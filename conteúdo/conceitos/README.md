# Conceitos

Em 02/11/2026 os conceitos e jobs do piloto foram retirados; `index.json` está vazio. O normalizador genérico foi preservado e agora exige especificações explícitas por `--concept-specs`; não carrega mais uma lista curricular embutida.

A normalização mantém a relação entre conceitos, classificações e excertos, rejeitando lacunas e atribuição duplicada. Os testes usam dados sintéticos de formas abstratas.

Consulte o [planejamento único](../../docs/plans/2026-11-02-planejamento-conteudo-radiant.md) antes de produzir novos conceitos.
