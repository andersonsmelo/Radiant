# App Store Listing Matrix

## Regra de uso

- `pt-BR` e `en-US` são mercados de primeira classe;
- qualquer mudança de listing precisa declarar hipótese e janela de leitura;
- listing não muda sem alinhamento com onboarding, valor inicial e qualidade técnica;
- screenshots e captions devem contar a mesma história do produto.

## `pt-BR`

### Posicionamento

- Promise: hábito diário de estudo em radiologia
- Outcome: aprender em blocos curtos e revisar com constância
- Hypothesis: enfatizar rotina e confiança clínica converte melhor do que copy
  carregada de features

### Metadata base

- Title: `Radiant`
- Subtitle: `Estudo diário de radiologia com quiz e revisão`
- Promo text:
  `Crie um hábito consistente de estudo em radiologia com lições curtas, feedback imediato e revisão espaçada.`
- Keywords:
  `radiologia,estudo,imagem medica,quiz,flashcards,revisao,habito`

### Screenshot narrative

1. Comece com uma jornada clara
2. Aprenda em blocos curtos
3. Teste seu raciocínio com quiz
4. Revise com repetição espaçada
5. Volte todos os dias sem fricção

### Reviewer notes base

`This build keeps the local-first study loop available even with network failure, supports account login, retries sync when connectivity returns and uses a controlled beta/release surface depending on build flags.`
