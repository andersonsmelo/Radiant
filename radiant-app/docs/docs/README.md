# Radiant — Engineering Rules (SDD)

Este projeto segue o workflow Specification Driven Development (SDD).

Regras:
- Nenhuma feature é implementada sem spec.
- Specs não são alteradas durante a implementação.
- IA executa código apenas a partir de specs.
- Mudanças exigem nova spec versionada.

PRD.md define O QUE o produto é.
Specs definem COMO o código deve ser escrito.
