## Folha de avaliação por aula

| Campo | Preencher durante a revisão |
| --- | --- |
| ID e versão | Preservar vínculo com progresso existente |
| Objetivo | O aluno será capaz de… |
| Pré-requisito | O que precisa saber antes |
| Fonte e revisão | Referência primária, atualidade, atribuição/licença e revisor |
| Explicação | Relação central, em linguagem adequada |
| Exemplo | Situação coerente com o objetivo |
| Ação do aluno | Escolher, comparar, associar, ordenar, localizar ou explicar |
| Distratores / erros | Qual confusão cada opção revela |
| Feedback | Por que acerta/erra e o que tentar em seguida |
| Mídia / movimento | Função pedagógica, autorização, controle e alternativa acessível |
| Retenção | Item de recuperação posterior, separado da prática |
| Evidência | Revisão de domínio + teste técnico + observação de uso, separadamente |

## Limites desta entrega

Inventário e proposta, sem mudança nas aulas, no app, no build ou na loja. Não declarar a revisão pedagógica concluída porque o diagrama foi criado. Pendentes: escolha curricular, aprovação visual, autoria/revisão, implementação, avaliação com alunos e validação física.
